# Tanvi Ranjan — Personal Portfolio

A warm, personal portfolio website for university applications — showcasing academic, sports, leadership, arts, and community achievements.

**Live site:** https://tanviranjan.com

## Stack
- **Framework:** Next.js 15 (App Router)
- **Styling:** Inline CSS with CSS custom properties (design tokens)
- **Fonts:** Playfair Display + DM Sans + DM Mono (Google Fonts)
- **Deployment:** Vercel
- **Domain:** Namecheap → tanviranjan.com

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Sections
1. **Hero** — Name, tagline, stat pills
2. **About** — Personal story + photo
3. **Academics** — Subjects, grades, achievements
4. **Sports** — Sports, levels, achievements
5. **Leadership** — Roles, timeline
6. **Arts & Culture** — Performing, music, visual arts
7. **Community** — Service initiatives
8. **Awards** — Full awards gallery with certificates
9. **Contact** — Email, CV download

## Deploying to Vercel
1. Push to GitHub (already done)
2. Go to [vercel.com](https://vercel.com) → Import this repo
3. Add custom domain `tanviranjan.com` in Vercel Dashboard
4. In Namecheap, point DNS to Vercel's nameservers

## Customising Content
- All placeholder text is clearly marked with `ADD ...` labels
- Replace grades in `Academics.tsx`
- Replace sports in `Sports.tsx`
- Replace awards in `Awards.tsx`
- Add photo in `About.tsx` (replace the placeholder div with `<Image>`)
- Update contact email in `Contact.tsx`
